## Nowadays

Software Engineer / Go Developer / Vibecoder @ [T-BANK](https://tbank.ru)

I build a platform for online recommendation systems. It consists of a framework and a set of microservices. I work where backend engineering meets R&D. I design and implement support for [Perseus](https://github.com/perseus2026/perseus), DCN, SeqCTR, and generative models such as OneRec in our online orchestrator. All of them have to run within a tight latency budget.

I'd never worked on recommendation systems before joining the team. Turns out they're a lot of fun!
